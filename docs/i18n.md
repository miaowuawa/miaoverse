# 国际化语言包

服务启动时会加载语言包目录中的 `*.toml` 文件。默认目录为 `./locales`，也可以在 `config.yaml` 中配置：

```yaml
i18n:
  dir: "/app/locales"
  default_language: "zh-CN"
```

容器部署时，可以把宿主机语言包目录挂载到配置的 `i18n.dir`，例如挂载到 `/app/locales`。

## TOML 格式

每个文件对应一种语言。文件名可以是 `en-US.toml`，也可以在文件内显式指定：

```toml
language = "en-US"

[messages]
"ok.login" = "Login successful"
"error.sms_provider" = "SMS service temporarily unavailable, please try again later"

[plurals."mail.unread"]
zero = "No unread messages"
one = "{{count}} unread message"
other = "{{count}} unread messages"
```

## 调用方式

普通消息：

```go
i18n.Message(ctx, i18n.OKLogin)
```

带命名变量：

```go
i18n.T(ctx, i18n.ErrSMSProvider, i18n.Data{"error": err.Error()})
```

单复数：

```go
i18n.Plural(ctx, "mail.unread", count, nil)
```

语言选择来自请求头 `Accept-Language`。如果请求语言不存在，会回退到默认语言，再回退到内置 `zh-CN`。
