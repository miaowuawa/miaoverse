# 配置文件指南

本项目启动时会从运行目录读取 `config.yaml`。当前 `main.go` 使用：

```go
ConfigService.InitConfig("./")
```

因此本地开发时，通常把 `config.template.yaml` 复制为 `config.yaml`，再按环境填写。配置格式为 YAML，字段名需要与模板保持一致。

## 基本规则

- 不要提交包含真实密码、AccessKey、短信平台密码的配置文件。
- 空字符串可以留空，但数据库、Redis、短信和 S3 等启用的服务必须填写对应必需项。
- 时间类配置需要注意单位：数据库连接时间是分钟，S3 临时签名和临时链接是秒。
- 布尔值使用 `true` 或 `false`，不要写成字符串。
- 字符串里如果包含特殊字符，建议加英文双引号。

```yaml
  log_level: "debug"

  max_idle_conns: 10
  conn_max_lifetime: 60
  conn_max_idle_time: 10

redis:
  host: "127.0.0.1"
  port: 6379
  username: ""
  password: ""

mongo:
  enabled: false
  host: "127.0.0.1"
  port: 27017
  username: ""
  password: ""
  auth_source: ""
  db_name: ""
  max_pool_size: 100
  min_pool_size: 10
  connect_timeout_seconds: 10
  server_selection_timeout_seconds: 30

session:
  dbnum: 0

smsreq:
  rate_limit: 5

i18n:
  dir: "./locales"
  default_language: "zh-CN"

smsbao:
  gateway: "https://api.smsbao.com/sms"
  username: "your-smsbao-username"
  passwd: "your-smsbao-password-or-md5"

s3:
  enabled: false
  endpoint: ""

  access_key_id: ""
  secret_access_key: ""
  session_token: ""
  bucket: ""

  temp_signature_expire_seconds: 600

  max_file_size_bytes: 20971520

  dbnum: 2
```

## server

```yaml
server:
  port: 8080
  log_level: "debug"
```

- `port`：HTTP 服务监听端口。
- `log_level`：日志级别。当前配置结构会读取该字段，具体日志行为取决于后续服务启动逻辑。

## database

```yaml
database:
  host: "127.0.0.1"
  port: 3306
  username: "miaoverse"
  password: "your-db-password"
  db_name: "miaoverse"
  max_open_conns: 50
  max_idle_conns: 10
  conn_max_lifetime: 60
  conn_max_idle_time: 10
```

数据库使用 MySQL，程序会拼接为：

```text
username:password@tcp(host:port)/db_name?charset=utf8mb4&parseTime=True&loc=Local
```

- `host`：数据库地址。
- `port`：数据库端口。
- `username`：数据库用户名。
- `password`：数据库密码。
- `db_name`：数据库名。
- `max_open_conns`：最大打开连接数。
- `max_idle_conns`：最大空闲连接数。
- `conn_max_lifetime`：连接最长生命周期，单位分钟。
- `conn_max_idle_time`：连接最长空闲时间，单位分钟。

本地开发可以使用较小连接数；生产环境按数据库规格和服务并发量调整。

## redis

```yaml
redis:
  host: "127.0.0.1"
  port: 6379
  username: ""
  password: ""
```

Redis 用于 session、短信验证码等服务。

- `host`：Redis 地址。
- `port`：Redis 端口。
- `username`：Redis 用户名。没有用户名时留空。
- `password`：Redis 密码。没有密码时留空。

## mongo

```yaml
mongo:
  enabled: false
  host: "127.0.0.1"
  port: 27017
  username: ""
  password: ""
  auth_source: ""
  db_name: ""
  max_pool_size: 100
  min_pool_size: 10
  connect_timeout_seconds: 10
  server_selection_timeout_seconds: 30
```

MongoDB 用于文章等内容文档存储。

- `enabled`：是否启用 MongoDB。为 `false` 时不初始化连接。
- `host`：MongoDB 地址。
- `port`：MongoDB 端口，未配置时默认 `27017`。
- `username`：MongoDB 用户名。没有用户名时留空。
- `password`：MongoDB 密码。没有密码时留空。
- `auth_source`：认证数据库。留空时使用 `db_name` 作为认证库。
- `db_name`：业务数据库名。启用 MongoDB 时必填。
- `max_pool_size`：连接池最大连接数。
- `min_pool_size`：连接池最小连接数。
- `connect_timeout_seconds`：建立连接超时，单位秒。
- `server_selection_timeout_seconds`：服务端选择超时，单位秒。

安全提示：

- 不要提交包含真实密码的配置文件；密码仅保存在本地 `config.yaml`。
- 连接失败的错误信息不包含连接串，凭据不会出现在日志中。

## session

```yaml
session:
  dbnum: 0
```

- `dbnum`：Fiber session 使用的 Redis DB 编号。

建议和短信验证码、缓存使用不同 DB，方便清理和排查。

## smsreq

```yaml
smsreq:
  rate_limit: 5
```

- `rate_limit`：当前代码中会作为短信验证码有效时间使用，单位分钟。

注意：字段名叫 `rate_limit`，但服务初始化时传给 `CodeExpireTime`，实际语义是验证码过期时间。

## i18n

```yaml
i18n:
  dir: "./locales"
  default_language: "zh-CN"
```

- `dir`：语言包目录。
- `default_language`：默认语言。

语言包编写方式见 [i18n.md](./i18n.md)。

## smsbao

```yaml
smsbao:
  gateway: "https://api.smsbao.com/sms"
  username: "your-smsbao-username"
  passwd: "your-smsbao-password-or-md5"
  head: "【Miaoverse】"
  dbnum: 1
```

- `gateway`：短信宝接口地址。
- `username`：短信宝用户名。
- `passwd`：短信宝密码或平台要求的密码摘要。
- `head`：短信内容前缀，通常是签名。
- `dbnum`：短信验证码使用的 Redis DB 编号。

## s3

```yaml
s3:
  enabled: true
  endpoint: "https://s3.example.com"
  region: "auto"
  access_key_id: "your-access-key"
  secret_access_key: "your-secret-key"
  session_token: ""
  bucket: "miaoverse-content"
  public_base_url: "https://cdn.example.com"
  use_path_style: true
  temp_signature_secret: "a-long-random-secret"
  temp_signature_expire_seconds: 600
  temp_link_expire_seconds: 300
```

- `enabled`：是否启用 S3 服务。为 `false` 时不会初始化 S3。
- `endpoint`：S3 服务地址。AWS S3 可以留空；Cloudflare R2、MinIO 等兼容服务一般需要填写。
- `region`：区域。AWS 按实际区域填写；部分兼容服务可填写 `auto`。
- `access_key_id`：访问密钥 ID。
- `secret_access_key`：访问密钥 Secret。
- `session_token`：临时凭证 token。使用长期 AK/SK 时留空。
- `bucket`：桶名称。
- `public_base_url`：公开访问基础地址，用于拼接对象公开 URL。
- `use_path_style`：是否使用 path-style 地址。MinIO 和部分兼容服务通常为 `true`。
- `temp_signature_secret`：生成用户临时签名的密钥。建议使用独立强随机字符串。
- `temp_signature_expire_seconds`：用户临时签名有效期，单位秒。
- `temp_link_expire_seconds`：S3 预签名临时链接有效期，单位秒。

安全建议：

- `temp_signature_secret` 不要和普通登录密码、数据库密码共用。
- 如果 `temp_signature_secret` 留空，服务会回退使用 `secret_access_key` 作为签名密钥；生产环境建议显式配置。
- `temp_link_expire_seconds` 不宜过长。当前服务限制最大不超过 7 天。

## upload

```yaml
upload:
  max_file_size_bytes: 20971520
```

- `max_file_size_bytes`：单个用户上传文件最大大小，单位字节。

该值会同时用于 Fiber 请求体大小限制和上传接口业务校验。未配置或配置为 `0` 时，默认值为 `20971520`，即 20 MiB。

## cache

```yaml
cache:
  dbnum: 2
```

- `dbnum`：预留的缓存 Redis DB 编号。

当前配置结构会读取该字段，具体缓存服务接入时再按模块使用。

## 常见问题

### 启动时报“读取本地配置文件失败”

确认运行目录下存在 `config.yaml`，并且启动路径和 `InitConfig("./")` 对应。

### 启动时报“解析配置失败”

通常是 YAML 格式错误，例如缩进不一致、布尔值写成中文、数字字段填了非数字字符串。可以先对照 `config.template.yaml` 检查字段层级。

### S3 初始化失败

当 `s3.enabled: true` 时，至少需要填写：

```yaml
s3:
  region:
  access_key_id:
  secret_access_key:
  bucket:
```

如果使用兼容 S3 服务，还需要检查 `endpoint` 和 `use_path_style` 是否符合服务商要求。
